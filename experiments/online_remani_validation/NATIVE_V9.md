# V9 联合接口实验：代码已实现，整体性能验收未通过

**不要替换实车，也不默认替换 V8。** 新版是隔离 ROS 数值仿真；不是 Gazebo、实车或完整全身 MPPI。
固定机械臂，无 CBF-QP。保留所有失败结果。

## 本轮实际改动

1. **同帧分类输入**。隔离检测器把原始点映射回其实际参与聚类的 PCL 体素，
   随同一时间戳发布全部有效测量点的目标 ID、速度、置信度、动态标签。
   只使用已确认且满足运动条件的目标；不是按目标包围圆删除附近点。
   `/sim/classified_cloud` 不向生产检测器安装任何修改。
2. **统一碰撞输入**。`classified_frame.py` 原子构建“PCD + 未确认/静态测量”的距离场，
   以及由完整动态测量外形形成的 CV 目标。PCD 始终保留，即使位置与动态点重叠。
   遗漏字段、非法标签、过期数据拒绝；地图改变使旧帧失效；迟到帧不覆盖新帧。
   分层模式下不再混用另一个时间戳的 `/dynamic_points`。
3. **统一静态候选搜索**。删除无动态目标时直接跳过 V7/V8 可行性搜索、恢复搜索的分支。
   静态场景也会比较候选并显式报告 `no_feasible_candidate`。
4. **初始静态余量不足的恢复**。实测已进入期望余量内、但保守车体净间距仍严格为正时，
   可评估离散预测净间距不减、终端恢复原 0.10 m 余量的动作。
   已发生保守车体重叠、存在动态目标或预测间距恶化时，不允许这种恢复。
   这属于初始不可行状态的特殊恢复，**不能说过渡过程始终满足 0.10 m 余量**，
   也不是连续时间/真实感知误差下的安全证明；已保持为实验功能。
5. 新增单元测试、失败状态回放、参考来源审计和简洁双栏 GIF。
   执行统计包含原生取消期间的全部停车，不能只统计 MPPI 获准执行的时段。

## 明确保留/未完成

- 速度、加速度、车体几何、CV 不确定性（仍为零）、动态时域参数未调大/调小。
- REMANI 规划器与原控制器二进制保持原样；上层取消、限速、观测新鲜度、50 ms 超时约束没有绕过。
- **还没有实现 REMANI 对 MPPI 局部执行轨迹的验收/授权协议**。
  当前安全检查仍可能根据旧 REMANI 参考取消整条轨迹，即便 MPPI 已找到可行绕行。
- 原生规划器 exit -11 再次复现，GDB 复测没有复现；没有定位/修复，不能宣称已解决。

## 验证结果

完整记录及 GIF：[结果目录](results/native_v9/README.md)。

- 最终静态复测到达目标，但从运动触发到结束约 27.80 s，旧版为 26.88 s；没有整体提速。
- 最终动态复测：非影子 MPPI 零可行候选周期从旧版 51 降到 0，说明局部瓶颈得到改善。
  但原生取消发生在 t=17.962 s，新参考直到 t=24.391 s 才收到，执行停车约 6.30 s。
  从运动触发到结束从旧版 22.62 s **变成 27.08 s**，不能说整套避障变好了。
- 同一最终构建改回 `--perception merged`，零可行候选为 40 个周期。
  支持“分层输入减少了局部无解”的判断，但各次在线规划/调度非确定，不能当作严格同输入或统计显著因果验证。
- 三组最新静态、动态、merged 对照均到达既有终点判据，未记录保守投影碰撞；这不是实车安全认证。
- 静态搜索 P95 内核耗时从旧记录约 21.6 ms 增至约 41.1 ms，有性能退化，仍需优化。

因此：本轮实现了接口与搜索改动，但**联合系统效果验收未通过，不提升为默认版本**。
下一步应独立设计局部轨迹验收：明确有效期、地图/目标版本、预测状态与完整固定臂外形校验；
验收通过才允许沿局部轨迹继续运行。真实碰撞、输入过期和验收失败仍须保留停车权。
不能直接解除 ABORT，也不能继续用调权重掩盖控制权限冲突。

## 使用与回退

```bash
cd /home/l/remani_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
# 明确指定实验构建，结果目录必须是新的。
python3 experiments/online_remani_validation/run_native_mppi.py \
  --build experiments/online_remani_validation/builds/native_v9_03 \
  --scene crossing --duration 45 \
  --out experiments/online_remani_validation/results/my_v9_crossing
```

`--scene static/empty` 切换场景；`--perception merged` 仅回到旧的合并输入做消融，
不表示关闭静态扩展搜索。完整回退指定 `--build .../builds/mppi_v8_09 --perception merged`。
`run_native_mppi.py` 默认构建仍为 V8，旧实验和生产源码未覆盖。

复建使用 `build_native_v9.py --out <新构建目录>`；复制原生快照并仅编译实验检测器及 MPPI 库。
单测：`test_contracts.py`、`test_native_v9.py --build .../native_v9_03 --out <新JSON路径>`。
后者依赖本轮保留的两份失败状态；它们不能删掉或混入成功结果。
`test_voxel_membership.cpp` 检查负坐标等情况下 738 个原始点到 72 个 PCL 源体素的精确关联。
