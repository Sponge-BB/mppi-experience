# 2026-10-27：MPPI适配REMANI三维碰撞模型

用户授权：实施碰撞模型方向调整并运行实验，提供直观GIF。不授权本轮实车控制、上线、上传或关机。

## 目标与判据

取消后来给REMANI额外叠加的二维整机投影硬门及对应附加空间惩罚，让MPPI适配REMANI原生三维采样几何和ESDF，而非反过来。只验证固定机械臂、差速底盘；不声称活动机械臂、完整三维动态安全或实车已验证。

共同模型包含真实Piper安装外参、底盘/机械臂球采样、原生硬门safe=false的半径/地图离散补偿，以及原生环境软裕度。保留原生轮限制、地面、当前自碰撞策略、感知有效性、指令租约及制动复核。Piper当前自碰撞跳过是继承的已知限制，不在本轮悄悄修复或宣称消失。

MPPI候选代价、可行性、提案筛选、发布前复核和制动均要使用新三维后端。旧二维图只作提案信息/可视化，不能继续据二维整机投影判不通而删掉三维可行候选。三维输入无效时fail closed，不退回旧二维放行。

## 最小实验

1. 单元与原生接口一致性预检：地图坐标、三线性插值、底盘与臂半径、原生接口同态检查、三维高度区分、动态时标、失效和制动分支。
2. 预检通过后，同一个新二进制OFF/ON，公共导出观测开启，比较额外二维合同与原生三维合同。旧父构建保持原样供回退；OFF带共同观测开销，不称旧二进制逐字基线。
3. 预声明单seed11、静态static/横穿crossing/正迎面dynamic_head_on_center，3场景×2组。每场完整原生REMANI在线重规划+实际MPPI执行，最多55秒。全部失败保留，不按效果换种子。预检、开发、正式结果分目录。
4. 两组同样固定机械臂、原有速度/轮限制、优化预算、300次上限、signed低速策略、感知与场景运动；不同时加入新的耦合目标、CBF或轨迹前缀。
5. GIF每场单独整理、同时间对照，显示实际REMANI参考、底盘/固定臂几何、已执行运动和真实MPPI搜索子集，标注简洁。图像只由真实记录生成。

## 地图与安全边界

- 大三维ESDF快照只在原生单writer队列读取，导出原始native栅格，不另建MPPI静态地图；独立队列只读immutable缓存并继续发送真实动态快照，不能在规划忙时饿死快层输入。
- static map acquisition/ESDF sequence、dynamic observation stamp、heartbeat时间分别记录，不能把心跳当新地图。
- 动态保留完整三维点云外形及恒速预测、同track同velocity分组平移最近邻，不能偷偷换成更大单球或新增不确定性半径。本轮不确定性参数为零。
- 原仿真器的二维投影碰撞记录不再作为任一组的自动终止标准；双方以同一原生3D球几何对真实有限高圆柱/墙作独立碰撞评价。原二维指标保留但不得冒充真实3D碰撞。
- 静态大快照更新时间受原生队列约束，新静态障碍地图响应仍需单独审计，不能因引入三维查询就宣称全部线程阻塞问题解决。
- 编译/重绘不与计时闭环并发，生产src/devel和旧结果不改。
