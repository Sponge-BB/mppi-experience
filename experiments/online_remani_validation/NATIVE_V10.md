# V10：局部执行权限与统一执行轨迹检查

这两项接口已接入隔离 ROS 数值仿真。固定机械臂，只控制底盘，无 CBF-QP。
最终构建为 `builds/native_v10_06`。动态测试与指令审核通过；**静态绕行回归未通过，仍是实验版**。
不是 Gazebo 或实车部署；生产源码的 98 项哈希与父构建相同。旧入口的默认构建仍保留。

## 分工与实际改动

```text
REMANI 在线规划 → 完整、带目标标识的参考轨迹包 → MPPI 候选控制序列
                                                      ↓
最新实测状态 + 同帧静态地图/CV目标 + 固定臂外形 → 快速执行审核
                                                      ↓
                                       审核通过的局部轨迹 + 有效期指令
```

1. **执行权限**：协同模式由快速执行层负责底盘，REMANI 更新参考不自动撤销局部运动。
   原生参考碰撞只请求刷新；原生旧参考的 `safety_speed_limit` 在此模式中是参考侧诊断，
   不再作为另一条实际运动轨迹的制动依据。它没有被全局删除，`--execution native` 恢复原流程。
2. **统一检查对象**：从内核读取选中的控制序列，基于发布前最新状态和最新同帧碰撞输入重新展开，
   检查包含固定机械臂的保守二维投影外形、静态点、CV 目标、轮速/速度限制。
   轨迹以约 10 ms 间隔审核；实际模型仍包含惯性滞后和加速度/轮加速度约束。
   `/planning/local_execution_rollout` 发布的是审核通过的执行轨迹，不能把搜索引导线当成它。
   REMANI 消费这个结果，执行安全不等待其繁忙的规划线程逐周期确认。
3. **制动后备动作**：独立检查“首动作持续 75 ms，然后制动，低速稳定 100 ms”的运动。
   候选无碰撞但该后备动作发生预测碰撞，仍拒绝下发。真实动态障碍不能保证停车永远安全；
   拒绝后请求零速是故障应对，不宣称它在任意闯入下都安全。
4. **指令有效期**：隔离被控对象只接收 `/sim/local_execution_cmd` 的带时间戳指令，
   75 ms 后没有新指令就制动；`/sim/cmd_vel` 在协同模式仅作观测，不是第二个执行入口。
5. **目标及参考事务**：使用原始目标消息的序列化标识，把完整原生 `PolynomialTraj` 分段一次交付。
   全部段验证成功才更新；旧目标的迟到结果忽略，损坏轨迹停止执行。
   参考版本更新保留控制序列热启动，清理旧几何引导缓存，不强制插入零速。
   基础参考只向量化采样 x/y 多项式，避免逐点解码八维位置及导数长时间占用执行锁；
   系数仍完整验证，并专项核对与原生标量采样的一致性。
   **真正的 ACTION_ABORT/WARN_IMPOSSIBLE 仍停止执行**，不能靠释放限速恢复被取消的旧参考。
6. **输入保护**：下发前检查里程计、同帧碰撞输入、检测健康、固定臂关节状态；
   更新/审核/指令发布与这些回调互斥，避免检查期间输入改变。
   超过 50 ms 的计算不下发非零动作。CV 时域随计算耗时缩短，只审核仍有效的选中前缀；
   不额外外推障碍物，不恢复已取消的不确定性半径。
7. **慢规划入口**：协同重规划每次只等待一个固定 ESDF 版本，从实测状态生成参考，
   失败后有界等待再重试。修复原入口“第一处等待满足后第二处立即重新捕获版本”的追帧问题。
   所有原生候选校验仍保留；参考通过不代表局部运动自动通过。

## 已验证与未通过

最终运行时动态实验 `crossing_runtime_06` 人为延迟新参考交付 3 s：

- 延迟窗口 t=20.156～23.113 s，60 个周期中 60 个周期有非零前进动作。
- 到达目标；从运动触发到结束 20.34 s；保守投影最小净间距 0.127 m。
- 原生取消等待为 0；远离终点的最长低线速度段约 0.442 s，仍有校验拒绝、无可行候选和计算超时。
- 参考来源独立审核、执行记录审核通过。不是连续时间证明，也不是多次统计性能结论。

历史 V9 同类记录的取消停车约 6.30 s，运动到结束约 27.08 s。
GIF 是不同次在线运行的案例比较，不能将差值都归因于单一修改。

**静态失败完整保留**：`static_06`、`static_delayed_06` 和最终运行时 `static_runtime_06` 没有到达目标。
新的 REMANI 参考已收到、指令审核正常运行，仍大量选择零速/小幅转向。
`static_06` 的停滞快照显示：动态目标为空；候选搜索有很多可行候选，但选中运动进展为零；
沿新参考的名义动作在 MPPI 保守碰撞外形/距离场下仍冲突。
因此不能继续用执行锁解释这次停车，也不能只解除安全检查。
需要单独解决参考接续、局部拓扑引导与短时域成本之间的选择问题，尚未完成其因果消融。

7 项任务/事务/指令测试、8 项内核检查、既有 13 项接口测试通过。
真实取消会清空已经排队延迟的旧参考，防止它们随后误解除取消状态。
参考采样加速后，对四个场景独立记录的 7 条原生消息逐项比较，采样值完全相同；
这次本机检查总耗时从约 1.08 s 降到 0.024 s，不等同于规划内核的加速比例。
制动检查专门覆盖“候选本身不碰撞，但随后制动会撞上后方移动目标”的拒绝案例。
初始静态余量不足仍沿用 V9 的特殊恢复规则，不能说全程都保持 0.10 m 余量。
模型仍为差速底盘和固定臂保守二维投影；不代表完整全身三维动态安全检查。

## 启动与回退

```bash
cd /home/l/remani_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
python3 experiments/online_remani_validation/run_native_mppi.py \
  --build experiments/online_remani_validation/builds/native_v10_06 \
  --scene crossing --reference-delay 3 --duration 45 \
  --out experiments/online_remani_validation/results/my_v10_crossing
```

结果目录必须是新的。去掉 `--reference-delay 3` 为正常参考交付；`--scene empty/static` 切换场景。
脚本仅在 `127.0.0.1:11441` 启动数值仿真，无硬件节点。

回到之前的 V9：将构建改为 `builds/native_v9_03`，去掉参考延迟并加 `--execution native`。

实际生产工程无需回滚本轮内容，因为没有安装/替换其实车规划器或控制器。

RViz Fixed Frame=`world`，连接隔离 master：

- `/sim/mppi/native_reference`：REMANI 的实际参考。
- `/planning/local_execution_rollout`：审核通过的局部执行轨迹，Path。
- `/sim/classified_cloud`：同帧分类点云。
- `/sim/mppi_diagnostics`：授权状态、审核拒绝码、实际/候选速度、延迟参考数量。

`execution_audit.json` 与 `reference_audit.json` 分别审核执行和原生参考来源。

其余消息字段与全部多项式系数仍须匹配独立记录。
