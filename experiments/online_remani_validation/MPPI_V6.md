# V6：提前生成连续运动候选与动态占用分层验证

这是**实验版**，不是实车发布版。固定机械臂，仅控制底盘；无 CBF-QP。
实车 `src/`、launch、devel 没有修改。V5 构建和全部失败实验保留。

## 代码改动

1. 用按差速底盘及执行滞后展开的原参考轨迹，检查未来交会，而非只等当前地图挡住路径。
   预测仍限于观测年龄加未来时间不超过 2 秒。预测最小净距低于 0.8 m 时启用附加候选，
   连续四周期超过 0.88 m 时退出；这是计算触发阈值，不是停车距离，也不是新增碰撞膨胀。
2. 添加左右两侧连续运动弧线候选，包含不同转向幅度、速度及保持时间。
   先限制角速度反馈，再统一检查左右轮速度；避免过大的期望角速度把线速度一起压到接近零。
   这些只是候选，不设置最终命令的最低前进速度。
3. 在同一目标下比较候选：沿路进展、低速停留、轨迹偏离、近距离风险、控制变化；
   横穿目标添加“从其后方通过”的终端软偏好，不强制选择与障碍速度相反的方向。
   此偏好不能保证整段行为始终位于障碍后方，仍可能出现先向一侧、再向另一侧调整。
4. 每个 rollout 间隔增加中点碰撞检查；优先从通过检查的候选中选择。
   指数加权后的控制序列重新检查，失败则回退到已检查的候选。
   全部候选都不通过时请求制动，并明确标为 `unverified_brake`，不声称已证明停车安全。
5. 等待、原地转向、倒车、预测避让分别记录，不再把接近零线速度全部视为等待。
   V6 的 `local_phase.predictive` 才是当前所选方案的可行性诊断；旧 cost_components 是 V5 候选代价。
6. 增加可选 `online_set_classified_static` 输入。联合测量图中的动态目标不再必须
   同时作为静止障碍和 CV 预测障碍出现。仅在调用者提供可靠点归属后的静态距离场时生效。
   输入必须与联合场同尺寸、同原点、同分辨率，内存保持到本次调用结束；每步重新提交。
   未提交或尺寸不符时使用原联合图。静态障碍、原有车体组合圆、0.1 m 固定余量均未删除。

这是带结构化候选和启发式终端偏好的 MPPI 实验实现，不是原始论文 MPPI 的严格复现，
也没有递归可行性、连续时间安全性或全局最优性证明。

## 分层输入的重要边界

当前正式局部验证使用理想合成观测：障碍位置、速度和观测点归属均已知。
分层仅移除已标为动态的测量占用；目标仍以完整碰撞外形进入逐时刻 CV 检查。
这不是把目标从碰撞检测中删除，也没有增加不确定性半径。

**当前真实点云回调没有获得可靠的逐点动静态归属，因此没有在实车或完整在线 ROS 中启用分层。**
不能通过“在目标周围画圆清地图”接入，那会误删靠近人的墙、箱子等静态障碍。
未分层的中间实验仍出现停留增加、低于固定余量和未验证制动，说明仅换采样/权重并不够。
完整 REMANI 的上层取消、零限速、重规划失败仍是另外的执行约束，本轮没有绕过或修复。

## 分类与复现

- 构建：`builds/mppi_v6_07/`；回退：`builds/mppi_v5_02/`。
- 正式局部对照：`results/mppi_v6/validation_01/`，6 场景，每版本 3 个种子。
- 调试与消融：`results/mppi_v6/development_*/`，以及早期 `results/mppi_v6_development_01/`。
- 每个场景的 `data/` 保存全部原始记录，`gif/` 保存 V5、V6 及并排动画，`plots/` 保存曲线。
- GIF 固定展示种子 1，不挑最好结果；全部种子见各场景 `summary.json`。
- 历史 GIF 索引通过 `catalog_experiments.py` 建立链接，不移动或覆盖原始目录。

```bash
source /opt/ros/noetic/setup.bash
source /home/l/remani_ws/devel/setup.bash
python3 experiments/online_remani_validation/suite_v6.py \
  --old experiments/online_remani_validation/builds/mppi_v5_02 \
  --new experiments/online_remani_validation/builds/mppi_v6_07 \
  --fixture experiments/online_remani_validation/results/final_report/empty_mppi \
  --out experiments/online_remani_validation/results/mppi_v6/my_validation \
  --seeds 1 2 3 --separate-dynamic
```

不带 `--separate-dynamic` 可复现联合距离场模式；不能将分层后的结果宣传为只改 MPPI 权重的收益。
V5 对照保留旧联合场，所以本轮比较的是整套局部方法改动，不是单因素 MPPI 优劣。

## 不应掩盖的取舍

主场景的三次局部试验均消除了途中低速停留和倒车，但平均通行时间、路径长度及计算耗时增加。
“不停”不等于“更快到达”。应同时检查速度曲线、最小车体净距、路径长度、到达率和计算预算。
详见正式目录的 `结果汇总.txt`，其他场景的结果也必须同时呈现。

| 场景（每版 3 次） | V5 平均途中低速 | V6 平均途中低速 | V5 / V6 平均通行时间 |
|---|---:|---:|---:|
| 正常横穿 | 1.68 s | 0 s | 21.77 / 22.92 s |
| 反向横穿 | 1.30 s | 0 s | 21.58 / 22.87 s |
| 快速横穿 | 1.48 s | 0 s | 19.82 / 19.52 s |
| 改变交会时机 | 0.65 s | 0.87 s | 23.50 / 23.87 s |
| 静态障碍 | 0 s | 0 s | 20.63 / 20.63 s |
| 空旷 | 0 s | 0 s | 16.13 / 16.13 s |

低速定义为实际线速度绝对值小于 0.02 m/s，排除前 1 秒和距目标 0.15 m 内。
正式 36 次试验全部到达；V6 正常横穿三次最小净距最低为 0.187 m，改变交会时机时最低仅约 0.101 m。
后者仍有低速、短倒车，尚不能称为解决了所有动态避障问题。
V6 动态内核 P95 约 33 ms（V5 约 19 ms）；本次无内核超 50 ms，但这不代表完整回调满足 20 Hz。

最终参数的同种子分层消融：

- 不提供分层：V6 通行 33.30 s，路径 4.68 m，低速 0.60 s。
- 提供理想分层：V6 通行 23.50 s，路径 3.38 m，低速 0 s。

因此分层是重要输入条件，而不是可以隐去的实现细节。下一步接入真实感知时必须验证
逐点归属、时间对齐以及静态点不被误删，再进入完整 REMANI / Gazebo 验证。
