# V12：慢速目标感知、迎面侧绕与横穿让行

范围：原生 REMANI 在线规划/重规划 + 真实点云检测跟踪 + 固定臂底盘 MPPI 的隔离 ROS 数值闭环。
不是 Gazebo，也不是实车版本；无 CBF-QP、无不确定性半径。
当前候选 `builds/native_v12_07`，验证归档见 [validation_03](results/native_v12/validation_03/README.md)。
验证结论须以该目录实际结果及契约审核为准，不凭单场景或理想控制器测试认定成功。

## 改进内容

### 1. 修复慢目标被当成静态的输入问题

旧动态进入速度为 0.22 m/s，而迎面目标速度是 0.18 m/s。
统一 V12 检测配置为进入 0.12、退出 0.08 m/s，净位移至少 0.06 m、历史窗口 0.80 s。
身份、点数、方向一致性、运动效率、持续时间及感知健康检查仍保留；不是每个点独立预测。

体素仍负责聚类，但运动中心由同帧关联到该簇的原始点估计，避免粗体素跳变或停留使
慢速平移难以确认。完整碰撞点外形不变。已有连续平移证据时，不再仅因驻留时间把目标
学习为静态背景；已有背景锚点的空间释放条件仍保留。
控制器不接收场景真值：真值仅生成传感点云和独立评价碰撞。

### 2. 延长实际 MPPI 展开，而不只画长预测箭头

独立入口默认 CV 有效期 3 s，MPPI 展开由剩余有效期及观测年龄决定；2/3/4 s 均可显式测试。
约 40 ms 观测年龄时，实际控制序列分别为 1.9/2.9/3.9 s；发布前仍按最新观测裁剪复核。
同周期缓存预测外形、提前剪掉硬碰撞候选，并限制采样数量，避免时域加长后计算量线性失控。
这里改的是**局部 MPPI 的最大 CV 外推时长**；原生 REMANI 的
`dynamic_point_flow/max_prediction_time` 仍为 2 s，规划器二进制不变，便于区分局部修改贡献。
CV 有效期是模型允许外推的假设，不是测量在未来3 s必然准确的保证；观测新鲜度仍限0.35 s。

### 3. 区分迎面侧绕与横穿让行

名义轨迹发生实际预测冲突时才启用干预，不因远处有动态目标就直接侧转。
迎面目标采用持续世界坐标侧绕候选、宽角度前后向提案，并在绕行阶段暂时降低参考线约束；
达到所需横向净空后平行推进，名义回接通过完整碰撞检查后再接回真实 REMANI 参考。
侧向奖励有物理宽度上限，不是无限吸引，也不改变硬碰撞外形。

横穿目标使用减速、时间让行和短转向候选，保留较强参考约束，避免沿横穿目标方向一直追过去。
可行同物理绕行侧的候选做指数加权 MPPI 更新，均值仍完整复核；没有通过的均值不执行。
这包含几何/时间引导，并非宣称未经引导的纯 MPPI 能解决任意局部极小值。

当前分类使用目标在参考轴上的速度分量，不是通用相对速度策略。
任一迎面威胁会切换整个候选集的侧绕模式，混合场景及同向慢车仍需专项检验；不作全场景保证。

### 4. 修复绕行后接回及终点附近停滞

回接朝向评价使用当前可达到的参考连接方向，避免车体偏离参考时仍被原直线切向限制。
近终点加入小幅正反向位姿修正提案：选择可执行的前后向进近，先到达位置，再对齐最终朝向；
提案同样参与优化和发布前验证。评分阶段由实测初态决定，避免预测到达后需要大角度对齐的
费用突增，导致优化器宁愿停在切换边界之外。
终点评分用最终位姿距离减少量，而非最近参考分支的弧长：含前进/倒退尖点的真实参考，
最近投影可能仍落在前进分支，原评分会把必要的倒车修正错误计为“进度倒退”，导致选择静止。
没有新增禁止倒退，也没有用终点距离直接绕过碰撞检查。

尚未经历动态目标时仍用原静态控制策略；动态目标消失后，安全清空路线保留新回接/终点策略。
如清空路线存在静态碰撞或过小净距，则退回原静态规划策略。因此不能说“所有无动态周期完全等同原版”。

## 保留的边界

- 同一差速底盘及执行滞后，轮缘速度 0.2296 m/s、轮缘加速度 0.2975 m/s²，不提高速度。
- 同一固定臂三圆盘车体投影及 0.10 m 物理余量；不是点机器人。
- 同帧静态/动态碰撞输入、最新里程计、确切已选控制序列、独立短时制动复核。
- 45 ms 后不启动额外备选复核，完整计算超过 50 ms 仍零指令；75 ms 指令租约保留。
- 制动复核只检查制动至停车稳定，不保证来向障碍物此后永远不撞到停住的机器人。
- 三维原生 ESDF 与二维局部投影尚非完全相同几何；当前理想测量无真实遮挡、定位漂移或打滑。

## 使用与回退

```bash
cd /home/l/remani_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
python3 experiments/online_remani_validation/run_native_v12.py \
  --scene dynamic_four --prediction-horizon 3 --duration 52 \
  --out experiments/online_remani_validation/results/my_v12_four
```

输出目录必须不存在。其他场景名见 `dynamic_scenarios.py`，`dynamic_head_on_center` 为正迎面。
独立 master 为 `127.0.0.1:11441`，没有真实底盘或机械臂驱动。
整批复现：`validate_native_v12.py --out <新目录>`；仅绘图使用 `--render-only` 和已有批次目录。

回退运行原 `run_native_v11.py`，不覆盖生产工程；也可显式指定旧构建。
本版源码不安装到 devel，实车 source/launch 不改。
实现入口：`perception_v12.py`、`mppi_v12.hpp`、`build_native_v12.py`。
构建目录不可变；继续修改必须构建到新目录，不能覆盖已记录的二进制。
