# V9 实验记录：不通过整体性能验收

以新旧闭环记录为准，不以“局部优化器无解次数减少”代替机器人实际效果。
默认实验入口仍保留旧构建；没有部署实车。

## 最终构建 native_v9_03

| 项目 | 旧在线 V8 | 新在线 V9 |
|---|---:|---:|
| 静态：运动触发到结束 | 26.88 s | 27.80 s |
| 静态：最长低线速度指令段（远离终点） | 1.67 s | 0.85 s |
| 静态：路径长度 | 3.95 m | 4.10 m |
| 静态：最小保守投影净间距 | 0.110 m | 0.118 m |
| 动态：运动触发到结束 | 22.62 s | **27.08 s** |
| 动态：非影子 MPPI 无解周期 | 51 | 0 |
| 动态：最长低线速度指令段（含原生取消） | 2.65 s | **6.30 s** |
| 动态：最小保守投影净间距 | 0.124 m | 0.134 m |

低线速度包含转向，不等于完全静止；不是多种子统计。终点沿用原有判据。
新动态组在 t=17.962 s 被上层 ABORT，t=24.391 s 收到新参考；这段停车不能从指标中剔除。
关闭分类的同构建对照有 40 个无解周期、运动至结束 25.30 s，未触发同样的 ABORT。
这支持局部输入修正的作用，但也直接表明上层取消策略仍主导整体表现。

## 全部试验，失败不删

| 目录 | 构建 | 结果/用途 |
|---|---|---|
| empty_01 | native_v9_01 | 空旷接入烟测到达；期间有并行单元测试，不作计时基准 |
| crossing_01 | native_v9_01 | 动态到达，局部无解 4 周期；开发中间记录，不混充最终成绩 |
| static_01 | native_v9_01 | **超时**：硬性余量使静态扩展搜索全无解 |
| static_02 | native_v9_02 | **原生规划器 exit -11**：未定位，不算通过 |
| static_debug_02 | native_v9_02 | **超时**：初始净间距为正但低于新增 2 cm 恢复门槛；GDB 未复现崩溃 |
| static_03 | native_v9_03 | 静态到达，2 版真实参考，无记录碰撞；整体时间未改善 |
| crossing_03 | native_v9_03 | 动态到达，2 版真实参考，但上层取消停车约 6.30 s |
| crossing_merged_ablation_03 | native_v9_03 | 只关闭同帧分类，动态到达；局部无解 40 周期 |

最终恢复逻辑不再设任意 2 cm 资格门槛：要求初始保守净间距严格为正、
离散预测净间距不减、终端恢复原 0.10 m 余量。真正保守重叠仍拒绝。
这不是持续保持 0.10 m 的保证，更不是实车连续时间安全证明。

## 回归和安全范围

- `unit_tests_03.json`：4 项分类测试及 5 项内核检查，包括两份静态死锁回放、实际重叠不强行动作、动态场景不放宽。
- `tracking_unit_03.json`：最终构建的直线/曲线/倒车跟踪等回归。
- `test_contracts.py`：13 项接口契约，包含原生取消、轨迹版本、同帧快照、迟到帧、缺字段拒绝及发布时新鲜度复查。
- PCL 源体素映射 C++ 测试通过；原生规划/控制二进制未改，生产源码未改。
- 每次运行独立 11441 master，结束只关闭自己的进程组；未连接实车控制。

闭环记录之后补充了发布时的新鲜度/感知失效复查并作单元测试；上述性能数字来自各自冻结 runtime，
不是这项末端保护改动后的新一轮性能试验。

实现、使用方式、回退与未完成项见 [V9 说明](../../NATIVE_V9.md)。
