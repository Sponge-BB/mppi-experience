# REMANI 在线参考接入验证

本目录新跑真实原生 ROS 规划/重规划闭环，不是重画以前的固定参考结果。
控制器为 V8 MPPI、固定机械臂、无 CBF-QP；没有提高速度或延长时域。
原生源码 98 个文件与隔离构建记录哈希相符，本次未修改生产源码。

## 尚未解决

- 首轮原生规划器段错误未定位；两次后续静态测试成功不等于修复。
- 动态横穿仍出现 7 次 `deadline_miss`，静态普通复测 2 次；仍保留 50 ms 超时保护。
- 静态普通复测有 14 个控制周期受 `native_safety_stop` 限制，不是全程连续避障。
- 终点沿用既有位置/朝向/线速度及 1 s 判据，未额外约束角速度。
- 单目标合成点云场景不是 Gazebo、实车或多目标统计对比，不能据此断言 MPPI 优于原版。

每次结果包含当时的 `runtime/` 脚本快照和 manifest。首轮验证后仅继续加强了安全限速互斥、
失败退出识别与正常关闭处理；最终版本的普通静态验证为 `static_02`。
全部进程由隔离启动器清理；没有启动实车节点，也没有改写旧实验结果。
