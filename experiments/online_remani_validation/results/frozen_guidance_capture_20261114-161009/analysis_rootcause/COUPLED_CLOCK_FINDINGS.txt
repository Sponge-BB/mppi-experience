Metric caution:
Strict adjacent-row flips are zero because rejection zero commands can separate opposite delivered commands. Filtering |w|>=.05 yields 4 sign changes; only the two described above are attributed to the identified guide discontinuities. The other changes include ordinary smooth path turns and must not be called oscillation. Report includes all rows to inspect.
Final position error .06308 m, yaw error .38564 rad; terminal-yaw FSM is excluded, so these are native-phase completion errors, not full navigation acceptance.

Limits:
- This is a numerical compatibility experiment, not a recreation of all real vehicle dynamics.
- The rejection schedule follows recorded wall time rather than a recomputed perception pipeline.
- checked_at precedes actual command publication by an unmeasured small interval; Twist lacks a source header.
- Real-record input replay remains the primary evidence. This coupled experiment supplies an additional reproducible trigger, not a guarantee of hardware outcome.

Reusable environment: coupled_native_clock.simulate(guide=callback, delivery_events=events)
The callback receives (state, adapter, exact_polynomial, phase, scale, elapsed, kernel) and returns v,w. The existing production guide is the default.
