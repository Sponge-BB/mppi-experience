Read-only offline audit; no running code, ROS state, firmware, controller parameters or deployed binaries changed.
Stage metrics select ROS log source_t in each goal interval. First-valid-export metrics select the fusion timestamp in the interval, then match exact obs+fusion over all traces; outputs beyond the interval are explicitly counted.
p50/p90/p95/p99 use linear interpolation at (n-1)*q. Times ending _ms are milliseconds; cell counts are voxel counts; KiB values /1024 give MiB.
Fusion timestamp marks completed coherent occupancy update; input timestamp is the source LiDAR/cloud stamp. Only fusion-to-export is comparable to the 350 ms fusion-age threshold. The first valid export age excludes transport/consumer delay and later cached reuse.
CPU core percent = 100*delta(utime+stime)/(SC_CLK_TCK*delta monotonic seconds); 100% is one logical CPU, not whole-machine saturation. proc/PID/stat CPU ticks aggregate threads; per-thread ticks must not be added again. Current same-host SC_CLK_TCK and page size used.
Resource mono is sampled before the process scan and wall after it; process reads within one row are not simultaneous. Event alignment and short CPU intervals therefore have scan-time uncertainty. Interval duration uses mono, while event lookup uses stored wall endpoints.
proc/PID/schedstat refers to the main task only. Only Piper has per-thread schedstat snapshots. Wait is runnable scheduling wait, not I/O/sleep wait. Summed thread waits overlap and can exceed elapsed wall time.
Only five selected robot processes and four capture children were sampled. LiDAR driver, LIO, mm_controller, ROS, capture supervisor, desktop/IDE and kernel CPU are not included; no /proc/stat system total CPU, runqueue, PSI, per-thread map-worker wait or pswpin/pswpout was recorded.
Substring process matching also captured diagnostic bash/codex commands; these are excluded by stable actual robot PIDs. Their comm names and sample counts are retained, command contents omitted.
SwapFree decline shows more swap allocation/use net of release, not swap transfer rate or page-fault latency. Major faults may load file-backed pages; neither they nor SwapFree alone prove swap-caused stalls.
MapTrace final source time precedes target2 interval end; missing final generations cannot be assumed exported or failed. Source-code interpretations refer to current workspace files, not independently hash-verified deployed build.
First-valid-export age is conditioned on successful observed valid export; missing generations are retained separately and must not be inferred to satisfy the threshold. A few valid outputs slightly exceed 350 ms at the post-publish trace timestamp; the source checks age at callback entry before output assembly/publish.
