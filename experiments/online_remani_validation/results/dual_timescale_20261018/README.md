## 如何看GIF

- 橙色：当前采用的REMANI参考；蓝色：实际已走路线；绿色：获准执行的MPPI短轨迹。
- 机器人显示固定机械臂下的完整投影，不是一个点；碰撞以独立全投影审计为准。
- 浅色候选线只在有实际导出记录时绘制，是搜索子集，不是所有样本。
- 默认2倍播放；图中时钟为仿真时间。在线和独立回线的时间起点分别注明。
- 障碍箭头表示一秒速度方向/位移，不等于完整预测时域。
- 每份图片目录均有`visualization_audit.json`，保留输入哈希及绘图设置。
- 独立回线画面按机器人/参考路线取景；画面外障碍仍保留在原始数据和碰撞检查中。

## 可信度与范围

98项生产文件采用前后SHA256核验；实验仅生成新脚本、新构建及新结果目录。
完整在线试验只允许localhost:11441，`/base_mppi`为唯一模拟速度和规划进度发布者，
不能向`/cmd_vel`发布。实验终止时只清理本次拥有的进程。

完整在线测试使用合成点云、实际检测器、实际REMANI搜索优化和实际MPPI。
独立回线则绕过ROS/检测器，输入受控的理想障碍，专门测局部控制能力。
它不用于宣称实车感知、通信或硬件响应已经验证。

本轮没有把MPPI绕行轨迹接入REMANI初始化，也没有修改MPPI控制律或代价。
初始化反馈属于后续独立算法对照，不能由本轮结果提前宣称它必然有效。
本轮未请求也不会执行关机或上传GitHub。
