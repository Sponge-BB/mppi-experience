## 数据分类

- `formal_key_01`：四场景×四组×种子2，有限真实搜索记录，用于三个关键GIF。
- `formal_extra_01`：相同四组、四场景，种子3、4；无搜索记录。
- `paired_first_01`：首次刷新时固定任务/地图/时间；六快照，每组每快照重求解两次。
- `paired_eligible_01`：B组演化中首次存在可用MPPI前缀的请求；单独的条件总体。
- `negative_goal_01`：终点永久占据，A/D；不允许把抵达子目标当作完成。
- `endpoint_diagnostic_final`：记录失败状态的自由场局部核诊断；不是原传感器场在线重放。
- `endpoint_diagnostic`：同数据的初次制图版本保留，最终入口使用上面的final目录。
- `smoke_empty_01`、`smoke_static_01`：构建02开发筛查，含保留的失败，不混入正式统计。
- `smoke_compact_01`：构建03的十二次开发冒烟，不混入正式统计。

所有“goal/collision/timeout”结果均保留；只有进程崩溃、接口矛盾、记录不完整判为实验无效。
同设置/种子不是相同闭环状态；因果分析使用独立冻结快照，暂停诊断不计导航性能。
冻结诊断为保证搜索预算有效，独立构建改用墙钟判断搜索超时，在线构建保持原样。
同一快照重复求解两次，不当作两次独立导航实验。
