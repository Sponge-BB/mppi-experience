# 2026-10-16 定向诊断正式结果

先看[结论与后续建议](结论与后续建议.txt)，或包含全部明细的[实验结果与分析](实验结果与分析.txt)。

这是隔离原生ROS数值诊断，不是Gazebo或实车，不是72场独立导航试验。
4个首次刷新输入快照，每个18次配对求解：无细分计时的3预算×2轮速×2次，另6次细分计时。
全部主快照通过输入、原调用第一代价/梯度、冻结地图代次、ROS时间和二进制一致性审计。

`static_first_refresh_*`、`dynamic_four_first_refresh_*`保存原始求解输入、计时、日志和配置；
`tracking_01/02`保存冻结测试与固定参考CSV。辅助`../validation_04`的范围和限制单独声明，
其中一个辅助动态边界不等于原调用精确环境重放，不用于原生超时发生率或主批统计。

没有改变生产速度、算法或运动模型，也没有向真实机器人发送控制。
