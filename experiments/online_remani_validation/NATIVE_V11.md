# V11：静态绕行接续、发布前备选复核和原生搜索边界

范围：**原生 REMANI 在线规划 + 点云检测 + 底盘 MPPI 的隔离 ROS 数值闭环**。
固定机械臂、无 CBF-QP、无不确定性半径。不是 Gazebo，也不是实车上线版本。
最终候选构建 `builds/native_v11_08`；不替换旧默认入口，不修改实车 launch/source/devel。

## 改了什么

1. **静态候选的预测长度保持一致。** 静态基础搜索本来展开 3 s，但外层恢复搜索此前按动态
   CV 有效期截成约 1.8～1.9 s，截掉转弯之后的前进收益。本版静态内外层均为 3 s。
   动态仍受原有 2 s CV 有效期约束，随观测年龄缩短，未擅自延长动态预测。
2. **局部绕行不再必须等原参考变得可直接跟踪。** 完整可行、具有推进量且末端风险通过的
   静态绕行动作可以退出恢复状态。存在可用局部连接路径时，静态绕行提案、中间备选/加权选择及
   外层恢复均按连接路径的弧长进度评价，而非被遮挡原参考的弧长；绕行后仍接回实际 REMANI 参考。
   这是几何连接引导 + MPPI，不是声称纯 MPPI 已解决任意局部极小值。
3. **新参考切换保留控制热启动，清除旧的恢复/绕行侧决策记忆和几何缓存。**
   旧控制序列不能直接执行，仍在新状态/地图上复核。修正新目标与旧目标同编号参考 epoch
   可能共用进度的问题：进度键包含目标 generation。
4. **首选复核失败时，同周期有限尝试备选。** 输出最多 8 条不同的、内核可行候选；首选不通过
   发布前轨迹/制动复核时，剩余预算内尝试下一条。采用的确切序列写回热启动，并记录候选序号
   和每次拒绝码。45 ms 后不启动额外备选复核，完整计算超过 50 ms 仍不下发非零动作。
   没有通过的候选仍拒绝，不删除碰撞检查，不缩小车体或余量。
5. **减少无效计算。** 对已经违反硬碰撞条件、不会参与权重或排序的候选立即停止评分；
   可行候选仍完整展开，名义轨迹仍完整检查以保留冲突时间诊断。已有合格完整静态绕行时，
   避免重复大规模搜索同一动作。编译仍为 O2，无 fast-math。
6. **解除慢规划刷新的错误前提。** 即使上一周期没有局部轨迹获准执行，阻塞的原生参考仍可
   请求重规划；不能因为快层超时/拒绝导致慢层也不再刷新。请求刷新不授予运动权限。
7. **原生采样搜索边界检查。** 拒绝零/单节点、时间/方向数组不匹配等非法底盘种子；保护
   随机索引上下界。异常返回失败供上层重试，不把非法输入当成成功路径。
8. **完善验收判断。** GDB 暂停的原生进程可能没有触发 roslaunch 的死亡信息；验收现也检查
   SIGSEGV 等调试日志。局部控制独立到达目标不能掩盖原生规划器崩溃。

## 不变的安全边界

- 相同差速底盘、轮缘速度/加速度限制、惯性模型、固定臂三圆盘投影及固定 0.10 m 余量。
- 发布前使用最新里程计和同帧静态/动态碰撞输入，稠密检查确切控制序列及独立制动后备。
- 输入过期、真实目标取消、机械臂姿态不符、计算超时等仍禁止非零指令；75 ms 指令租约保留。
- 原先已有的静态余量不足恢复规则未删除；不声称所有时刻都保持完整 0.10 m 余量。
- REMANI 三维 ESDF 与局部二维投影不是完全相同的几何表示，仍需进一步统一与实车标定。

## 验证与证据边界

完整闭环与图片归档见 [实验索引](results/native_v11/README.md)。不能只看成功案例：

最终构建 08 的六次在线闭环均到达目标；均未记录到保守投影碰撞或原生进程故障，
参考来源审核和实际执行契约审核均通过。下表时间从实测运动触发算起，包含途中低速：

| 场景 | 到达用时 / s | 远离目标低线速度命令累计 / s | 最长低线速度段 / s |
| --- | ---: | ---: | ---: |
| 静态首次 | 26.21 | 1.54 | 0.90 |
| 静态复测 1 | 26.76 | 1.17 | 0.95 |
| 静态复测 2 | 26.28 | 1.26 | 0.95 |
| 动态，新参考延迟 3 s | 20.68 | 0.55 | 0.10 |
| 动态，正常交付 | 20.39 | 1.07 | 0.26 |
| 空旷 | 16.17 | 0 | 0 |

这里的低线速度指 `|v_cmd|<0.02 m/s` 且距目标超过 0.35 m，**包含转向，不等于完全静止**。
静态最小净距 0.121～0.154 m，动态 0.137～0.141 m；静态内核 P95 为 28.8～32.6 ms，
动态约 41 ms，仍有少量完整周期超时与候选拒绝，未宣称硬实时或完全不停顿。

与已保存 V10 案例比较：静态由时限内未到达，变为本轮三次到达；动态延迟案例低线速度命令
累计由 1.47 s 降到 0.55 s，但总到达时间由 20.34 s 变成 20.68 s，不能说所有指标都更优。
两次动态试验分别有 2、5 个周期实际采用通过发布前复核的备选。延迟窗口内 60/60 周期前进，
说明该窗口没有等待新参考而停住；不代表所有遇障时刻都能无停顿通过。

对照的车体几何、速度/余量参数、感知模式、运动触发规则和参考延迟一致。
旧运行时限 45 s、新版 52 s（从目标下发算起）；新版均在旧时限内到达。
这些是少量非配对在线案例，不是固定随机种子统计优势或全场景成功率。

以下失败均保留：

- `static_02`：超时大量累积、慢规划刷新受局部 Path 条件牵制，失败保留。
- `validation_02/static`：原生进程 SIGSEGV；`debug_static_04` 在随机整数分布处复现。
  调试时局部控制最终到达，但原生进程已故障，**不是整体验证通过**。
- `validation_03/static`：新增边界检查实际拦截 `nodes=0 times=0 directions=0`，随后原生
  新参考生成成功；没有崩溃，但机器人小幅进退、任务超时。这说明仅修崩溃和时域并不足够。
- `validation_04/static` 成功，但 `static_repeat` 失败。07 只统一主绕行与外层恢复，遗漏了
  中间备选/加权选择。本轮 08 才补齐该环节，不能把 07 的单次成功说成稳定修复。
- `held_reference/before` 与 `after`：保持同一条实际参考、同一初态、同一冻结静态距离场、
  随机种子 1 的局部检查，二者都满足早期位置/速度判据（未检查终点朝向）。**该重建未复现在线振荡，不能作为新评分解决全部问题
  的因果证明**；缺少历史控制器状态、传感变化、ROS 计算延迟及重规划交接。
- `guide_probe_07_complete/probe.json`：使用静态失败的真实状态/参考/距离场，但重新初始化控制器，
  可生成 143 点可用连接路径，并非该几何状态根本无路可走；不等于重放了历史内部状态。

单元与接口检查：6 项 V11 回归、7 项目标/事务测试、8 项执行内核测试、既有 13 项接口测试。
另有 5 项真实原生搜索代码边界测试。原生部分在 `native_v11_06` 检查，07 复用源文件哈希完全
相同的原生二进制（08 也使用该原生二进制）。V11 回归包含真实调用诱发恢复后，从历史停滞快照产生通过复核的 3 s 绕行；
8 条候选的导出/采用；最新全占据地图否决全部备选；动态预测不超出 CV 有效期。
本轮结束时，生产工程清单的 98 项源码哈希与父构建仍相同。

`pruning_equivalence_04.json` 是对剪枝前后同输入/同种子的 4 组、共 100 周期对照，
这些输入下输出完全一致；该结论只针对剪枝，不涵盖后续绕行评分变更，也不是全输入形式化证明。

## 复现和回退

```bash
cd /home/l/remani_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
python3 experiments/online_remani_validation/run_native_v11.py \
  --scene static --duration 52 \
  --out experiments/online_remani_validation/results/my_v11_static
```

输出目录必须是新的。`--scene empty/crossing` 切换场景；动态加 `--reference-delay 3` 是
参考交付延迟注入，不是改变障碍物速度。隔离 master 固定 `127.0.0.1:11441`，无实车驱动。

回退使用显式构建参数 `--build experiments/online_remani_validation/builds/native_v10_06`；
也可直接使用原 `run_native_mppi.py`。实车工程本轮无需回滚，因为未被修改或安装。
重新构建使用 `build_native_v11.py --out <新构建目录>`。05 是未完成的编译目录，不可运行。

主实现：`build_native_v11.py`、`execution_candidates.inc`、`local_execution.py`。
原生修改由构建脚本注入隔离源码，不覆盖生产工程。每个试验保存运行脚本、参数、哈希、
原始状态/障碍物/参考/执行记录；所有中途失败记录保留。

## 后续实车接入仍缺什么

本轮不是实车放行：需要把同一控制内核、同帧输入、命令租约/急停和唯一执行出口接入硬件
适配层，测量里程计时间、传感器延迟、底盘加速度/制动及打滑；先影子运行，再限速验证。
当前理想传感仿真无真实遮挡、定位漂移、轮胎打滑或机械臂运动，不能据此保证实车效果。
