# V7：风险监测与实际避让分开

范围：固定机械臂底盘、固定原参考的局部数值闭环，不是完整 REMANI、Gazebo 或实车。
所有更改仍在本实验目录；没有修改实车源码、launch、devel 或发布实车控制指令。
当前实验构建 `builds/mppi_v7_05/`；V6 `builds/mppi_v6_07/` 原样保留。

## 针对的问题和实现

### 1. 预测到风险，不等于立刻横向绕行

删除 V6 的 0.8 m 宽预警区动作逻辑与无条件的“从障碍后方通过”终端偏好。
每周期仍检查原参考的预测展开，但先比较原路跟踪与 0.8/0.55/0.3/0 倍引导速度。
根据首次预测冲突时间与转向/制动响应预算决定是否增加横向候选；若全部跟踪候选不可行，
也允许立即增加横向候选，不让时机门槛挡住可能的逃离动作。

响应预算考虑底盘/轮子速度、加速度、当前角速度、执行滞后和控制周期，
转向预算以 0.5 rad 为设计角度，属于启发式选择，不是通用 TTC 急停阈值，也不是安全证明。
远处没有冲突时，复用并重新检查 V5 的正常跟踪方案，避免仅因检测到目标就降低正常巡航速度。

### 2. 评价有效推进，不奖励无效侧向运动

用预测轨迹沿原参考弧长的增量计算推进速度，而不是只看车头方向线速度。
低推进惩罚、沿路进度、横向偏差、姿态误差和控制变化共同评价候选。
新增保持原路、降速、不同延迟开始转向、转向后反馈回接的候选。
先排除未通过采样碰撞检查的序列，再进行指数加权；加权结果也重新检查。
避免左右两组明显不同的路线直接平均；同侧策略给予软连续性偏好，但安全条件变化时允许切换。

### 3. 防止把风险留到预测末端

预测末端净距较小且仍在接近障碍物时，增加与当前制动响应有关的代价。
只使用当前预测时域内的间距变化，不把 CV 外推到有效期以外。
这是一项风险代价，不增加物理碰撞膨胀、不证明停车必然安全。
所有候选不可行时仍请求制动，并标记 `unverified_brake`。

### 4. 显式回接，不等待障碍物消失

连续四周期确认参考反馈跟踪的整个展开安全，且仍存在位置/朝向偏差时，切换到已检查的回接序列。
回接结束要求位置偏差不超过 0.04 m、朝向偏差不超过 0.15 rad，不能只看位置。
单元测试始终保留移动目标，验证回接不依赖障碍物列表变空。

### 5. 诊断与分层输入

保留 `online_avoidance_debug` 的碰撞可行性字段，新增 `online_decision_debug` 12 字段：
mode、首次预测冲突时间、响应预算、原路预测净距、侧向选择、候选编号、是否开启横向候选、
路径误差、预测有效推进速度、所选代价、连续安全周期、预测最大横向偏移。

mode：0 监测/跟踪，1 调速，2 绕行，3 回接，4 未验证制动。
ROS 实验适配器记录在 `local_phase.decision`；旧 cost_components 只属于 V5 候选，不代表 V7 最终代价。
过期或非法 C API 调用也会作废暂存的分类静态层，避免下次调用复用过期归属。

车体组合圆、0.1 m 固定余量、轮速/加速度约束、2 秒 CV 有效期均保留；未加入 CBF-QP，未禁止倒车。

## 实验设计及边界

- V6/V7 都使用相同的理想动态点归属分层，不再只给新版额外的分层输入。
- 横穿障碍物从出现起持续存在并按 CV 运动，不在场景计时 14 秒后删除。
- GIF 出画面时会标注“仍持续被观测”，不是控制器突然看不到障碍物。
- 7 场景：正常横穿、静态、反向横穿、更快横穿、改变交会时机、无交会风险的移动目标、空旷。
- 每版每场景 3 个种子；GIF 固定取种子 1，不挑最好结果。
- 同时统计路径长度、低线速度时间、低有效推进时间、侧向移动但不推进时间、最大偏移和净距。
- 有效推进指标按本组 +x 直线参考计算；不能直接套用到任意曲线或倒车轨迹。

当前仍假定准确的 CV 输入和可靠的动态点归属；没有完成真实雷达分层、完整上层重规划与执行权限验证。
单次候选无碰撞不等于递归可行，少量理想试验通过也不等于实车安全。

## 本轮验证结果及取舍

正式对照共 42 次（7 场景 × 2 版本 × 3 种子），全部到达目标，无未验证制动周期。
以下使用本轮持续障碍物场景重新运行的 V6，不能与旧版14秒移除障碍物的结果混用。

| 场景 | V6 平均通行时间 | V7 平均通行时间 |
|---|---:|---:|
| 正常横穿 | 22.13 s | 19.92 s |
| 静态障碍 | 20.63 s | 20.63 s |
| 反向横穿 | 21.97 s | 20.15 s |
| 快速横穿 | 18.90 s | 17.63 s |
| 改变交会时机 | 23.05 s | 21.08 s |
| 无交会风险的移动目标 | 15.33 s | 15.55 s |
| 空旷 | 16.13 s | 16.13 s |

正常横穿：平均路径 3.34 → 3.02 m，每次最大横向偏移的平均值约 26.8 → 3.4 cm。
V7 三次均未出现超过5 cm的横向偏移，因此不是简单把同样的大绕行动作延后，而是更多选择调速沿原路通过。
快速横穿仍有绕行：种子1的5 cm偏移出现时刻从3.40推迟到6.00 s，回接从13.90提前到10.50 s。
回接单元测试在目标持续被观测的情况下约4.2 s满足位置和朝向条件。

**不能隐去的退化：**

- 正常横穿平均低线速度时间由0增加至1.53 s，并有约3 cm后退；并没有解决所有停车问题。
- 正常横穿三次最低车体净距约0.187 → 0.103 m；部分其他场景最低仅略高于0.1 m。
  物理碰撞模型及固定余量没有缩小，但实际轨迹的额外净距减少了，不可据此认为实车安全余量充足。
- 较晚交会场景出现约0.12～0.14 m后退；不应把“没有左右大绕行”宣传成“没有动作反复”。
- 无交会风险场景平均慢约0.22 s，并非所有指标都改善。
- 动态内核P95约26 ms，低于V6约33 ms，但不是完整ROS回调实时性测试。

本轮结论：减少了过早横向偏移和绕行距离、改善了回接与部分场景通行时间；
仍是有理想感知假设的局部实验版，未达到“实车全程不停动态避障”的验收标准。
