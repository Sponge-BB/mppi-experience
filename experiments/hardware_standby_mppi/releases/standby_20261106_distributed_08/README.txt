08：l 端规划、hai 端 RViz 的隔离观察版本

当前能做什么
  保持原来的双机操作方式：l 运行传感器和规划，hai 打开 RViz 发布目标。
  已接通 hai 目标 → l 的原生 REMANI → 整机 MPPI → hai 显示/诊断。
  MPPI 直接读取收到的原生七次多项式：底盘路径和逐步六关节参考。
  默认入口只计算和显示，不包含底盘/机械臂驱动或硬件命令输出。
  不能用本次成功代替实际运动、动态避障或连续控制时序验收。

复现方法
  不要同时运行原整机 launch，避免雷达设备和 TF 冲突。
  l 端（192.168.137.128）：
    cd /home/l/remani_ws/experiments/hardware_standby_mppi/releases/standby_20261106_distributed_08
    ./bin/start_l_observation.sh --duration 180 --label view_$(date +%Y%m%d_%H%M%S)
  hai 端（192.168.137.107），在桌面终端运行：
    /home/hai/remani_distributed_08/bin/start_hai_rviz.sh
  等模型和点云出现、状态显示 shadow_candidate_only 后，用 2D Nav Goal
  在附近空闲区域点击并拖动朝向。目标只进入本次隔离规划器，机器人不执行。
  输入尚未就绪的目标不转发；就绪后重新点击，不排队自动启动旧目标。
  l 端到时或 Ctrl+C 会关闭本次进程；hai 端关闭自己的 RViz 即可。
  观察使用独立 ROS 主节点11462；脚本只设置自己的进程环境，不修改 .bashrc。
  当前无需另开 roscore。CAN 接口需保持之前已配置的接收状态。

怎么看结果
  彩色点：实测过滤点云；蓝/橙色球：实际反馈姿态对应的整机碰撞模型。
  绿色路径：实际收到的 REMANI 底盘路径；短目标的路径可能被车体模型挡住。
  每次记录在 reports/<label>/；native_reference.jsonl 保存原生系数和接收结果，
  shadow_*.jsonl（归档为.gz）的 kernel_diagnostics 记录实际 MPPI 参考和候选控制。
  reference_source=native_polynomial 且 proposed_controls 非空表示使用了原生参考。
  它仍只是候选，不表示底盘或机械臂已执行。

改动范围与限制
  复用已编译的原生规划器、原雷达/定位及原安装参数，不重新编译。
  08/runtime/active_arm_mppi.py 是07算法的独立副本：扩展逐步关节参考输入，
  并等价替换两处小数组裁剪表达式以减少开销；240组状态更新误差为0。
  目标经过真实输入就绪检查；原生轨迹的原时间戳保留，过期后不继续使用。
  原生消息没有完整批次结束标记或目标ID；当前以时间关联并等待30ms静默。
  已收到前缀之后的关节预测保持该前缀末端；整条前缀过期仍拒绝。
  底盘目前沿几何路径推进，机械臂按原生时间相位采样；未实现统一整机相位。
  本版本没有快层前缀反向注入慢层，不能称为完整的双向优化闭环。
  为控制内存，本次地图为6×6×2.5米、分辨率5厘米；world为本次局部里程计。
  没有验证原预建全局地图导航；不得把局部观察图当成完整已知自由空间。
  原生C++ Piper分支与Python碰撞检查不同；原生路径不能独立作为运动许可。
  当前是收拢机械臂和静态泡沫柱，不是移动障碍物避障对照实验。
  双机参考验证没有启动命令网关；后续待机时序短测结果单列如下。

待机命令时序短测（recording_timing_02）
  --recording 只启用原07网关与内存RecordingSink，无硬件输出，失败不自动重新启用。
  此诊断模式只覆盖待机；RViz导航目标会被拒绝，不将未绑定原生参考版本的包
  当作导航交付结果。普通观察模式的RViz目标功能不受影响。
  第一次试验5包后因旧定位超龄停止。修正为在原20ms同帧等待窗口内等待新定位，
  要求采样时定位/关节年龄留出原100ms命令预算，未放宽原时间限制或改源时间戳。
  60秒复测中，启动稳定后连续480包进入内存记录器，期间没有网关锁停。
  数据见 reports/recording_timing_summary.json；失败试验也完整保留。
  本次实验树峰值803.09 MiB、可用内存最低2942.82 MiB，硬件发送0、进程残留0。
  这是静止、收拢姿态、未开hai RViz的短时证据，不是长期或运动负载验收。
  尚未验证导航命令交付；执行阶段需将原生参考版本/取消事件绑定到命令验收。
  下一步需实物低速响应与停止验证：先机械臂，再底盘，之后才做动态障碍对照。
  实际展开、低速响应与停止测试前必须先通知用户；本次已停在这一边界。

  core、model依赖冻结07；反馈/传感器依赖冻结02，本目录不能单独拷走使用。
