standby_20261106_stationary_07 — 实车静止输入与 MPPI 命令接口准备

用途与边界
  本版本接入实际关节、定位、雷达，运行整机 MPPI，并可通过内存记录器
  演练最终命令复检。它不使能机械臂或底盘，不发送执行器命令。
  当前机器人为收拢姿态；沿用用户认可的原项目安装参数。
  07 的执行入口明确拒绝 execute=true，launch 中驱动通信也固定关闭。
  不要通过改 readiness 标志将影子观测结果当成运动验收。

本次改动
  复用原 PassThrough/CropBox、已编译的动态跟踪器、原定位和只收 CAN 反馈。
  静止时收集实际过滤点云作为局部背景，不使用旧地图冒充当前环境。
  合法的动态空帧可以表示“当前没有跟踪目标”；健康和时间检查仍必须通过。
  raw 保留输入新鲜度与可见性诊断，碰撞查询使用 filtered、background、dynamic。
  删除原始点云中真正的零回波；不删除非零的近距离实测点。
  只查询会影响碰撞和软代价的近场区域；远处间隙返回保守下界。
  相同关节姿态共用内部碰撞检查，候选恢复引导批量计算；没有减少候选或预测长度。
  无可视化订阅时跳过图形生成。新观测与定位回调唤醒检查，每个动态帧只求解一次，
  避免固定周期恰好先于传感器回调。95ms 决策期限和250ms输入新鲜度保持不变。
  同帧到齐最多等20ms，计入原95ms预算。已有20ms监测循环独立更新真实反馈及感知，
  不等待求解完成，不改测量时间，不重复用旧测量刷新年龄。
  交付截止与执行租约明确区分：旧调用仍保持较短expiry语义；07显式请求140ms执行范围，
  截止固定在最终验收开始时，不随验收结束或发送时间顺延。原源时间不改，总lease仍受250ms限制。
  完整租约、位置目标与制动路径都复检。旧调用验收限20ms；07显式140ms租约路径限30ms，
  为100ms位置目标保留至少10ms余量，传输返回后再查是否还剩100ms。源时间与交付截止不改。
  发送前再读取当前感知状态，交付过期、验收超时或感知失效仍拒绝/停止。
  停用回调在释放输入锁后才操作命令网关，避免与发送前检查相互等待。
  两条验收路径仅合并几何查询，采样位置和时间不变；没有减检查点、自动续租或自动重新使能。

这些证据没有覆盖的内容
  原CropBox较大的近场剔除区域、雷达看不到的近处高障碍仍未验收。
  静止背景与空动态帧不证明移动障碍识别有效；观察到的点云也不证明未知空间可通行。
  没有做实际驱动响应、机械臂展开、实物停止、移动底盘定位或原生/MPPI实车对照。
  计时来自短时运行，未验证开启RViz后的负载或长时间稳定性。
  验收预算与租约的时间匹配不代表实际传输、运动延迟和制动性能已经验证。
  连续MPPI命令时序尚未通过：当前共享主机上会超时并锁停，不能直接进入自主避障。

下一阶段的动作边界
  静止输入接入与离线接口检查完成；连续闭环时序仍需解决，尚未达到自主避障验收条件。
  可以独立推进的下一项是已有隔离驱动的实物响应验收，这一步需要实际运动并须先通知用户。
  当前姿态接管后，按原项目已知展开动作
  或经检查的路径低速展开机械臂，核对反馈跟随和停止，检查展开后机械臂附近的点云覆盖。
  当前收拢姿态几何间隙很小，不能随意改一个关节作为“微动测试”。
  再单独验证底盘低速响应及移动时定位。通过后才进入机械臂避障/底盘扰动对照。
  机械臂沿用原SDK/协议及已隔离的驱动封装；底盘沿用原UART驱动，无需重写。
  实车避障仍有覆盖和运动验收工作，不是只切换一个开关就完成。

复现（不要同时启动原整机launch）
  离线：/usr/bin/python3 tools/memory_bounded_run.py --label tests -- -m unittest discover -s tests -p 'test_*.py'
  静止观察需要已有02私有ROS主节点11461和原始雷达输入，且没有定位/执行器发布者：
    source bin/environment.sh
    export ROS_PACKAGE_PATH="$STANDBY_CONTROL_RELEASE:$STANDBY_CONTROL_RELEASE/../standby_20261105_feedback_02:/opt/ros/noetic/share"
    export LD_LIBRARY_PATH="$STANDBY_CONTROL_RELEASE/../standby_20261105_feedback_02/lib:${LD_LIBRARY_PATH:-}"
    export MALLOC_ARENA_MAX=2
    /usr/bin/python3 tools/run_stationary_preparation.py --duration 30 --label new_observation
  如需同时验证内存命令记录器，在上条命令末尾加 --recording。此选项不连接执行器。
  名称不可覆盖已有报告。单进程地址空间768MiB、实验子进程树RSS上限650MiB；
  启动前预留完整预算，运行时系统可用内存低于2.75GiB即停止，仅清理自己启动的进程。
  不重编译、不并行测试、不结束VSCode；不会自动关机。
